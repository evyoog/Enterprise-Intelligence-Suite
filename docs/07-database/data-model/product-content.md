# Data model — Product content (02.04)

**Status:** Built 2026-10-07 ([C81](../../01-business/roadmap/open-decisions.md#c81)) for [REQ-CAT-004](../../02-requirements/FRD/product-content/requirement.md). Migration [`V024__product_content.sql`](../../../database/migrations/V024__product_content.sql), mirrored in `backend/src/main/resources/db/schema.sql`. **Additive**: one new table, no existing table changes (applied twice on PostgreSQL 16; idempotent).

## product_content_item
One row per piece of content of one catalog product (application). One table with a `kind` column; the columns used depend on the kind.

| Column | Type | Notes |
|---|---|---|
| id | BIGSERIAL PK | |
| product_id | BIGINT NOT NULL → `products(id)` **ON DELETE CASCADE** | The files of a deleted application are removed from storage by `ProductDeleteListener` before the row goes |
| kind | VARCHAR(20) NOT NULL | `DATASHEET`, `DOCUMENTATION`, `IMAGE`, `VIDEO`, `CASE_STUDY` (CHECK) |
| title | VARCHAR(200) NOT NULL | |
| description | VARCHAR(1000) | |
| status | VARCHAR(20) NOT NULL default `DRAFT` | `DRAFT` / `PUBLISHED` (CHECK) |
| display_order | INT NOT NULL | Within the application; the admin reorders with the arrows |
| content_version | INT NOT NULL default 1 | Latest version only: +1 on every edit or file replacement ([C81](../../01-business/roadmap/open-decisions.md#c81) PC-5) |
| object_key | VARCHAR(500) UNIQUE | Private S3 key of the file (datasheet, image, case-study PDF). **Never a URL** |
| file_name, file_size, mime_type | VARCHAR(255), BIGINT, VARCHAR(100) | As declared and verified |
| alt_text | VARCHAR(250) | Required for images |
| logo_object_key (UNIQUE), logo_file_name, logo_file_size, logo_mime_type | | Case-study customer logo |
| video_provider | VARCHAR(20) | `YOUTUBE`, `VIMEO`, `EXTERNAL` (CHECK) |
| video_url, video_ref, thumbnail_url | VARCHAR(1000), VARCHAR(50), VARCHAR(1000) | `video_ref` = the provider's video id; the YouTube thumbnail is derived from it |
| customer_name | VARCHAR(200) | Case study |
| problem, result_text | TEXT | Case study (`result_text`: `result` is a reserved word in some databases) |
| knowledge_content_id | BIGINT → `knowledge_article(id)` ON DELETE SET NULL | Documentation: the linked knowledge article |
| published_at | TIMESTAMP | Set on publish, cleared on unpublish |
| created_by_sub, updated_by_sub | VARCHAR(100) | Keycloak subject of the administrator |
| created_at, updated_at | TIMESTAMP NOT NULL | `updated_at` is the "Updated on" date |

Index `idx_product_content_product (product_id, status, display_order)`.

## Storage keys
`product-content/{productId}/{kind}/{uuid}.{ext}` and `product-content/{productId}/{kind}-logo/{uuid}.{ext}` in the private knowledge bucket (`eis.knowledge.storage.*`). Generated by the backend, never from the file name.
