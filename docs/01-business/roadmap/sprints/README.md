# Sprints

One file per sprint ID found in [PO] (`2026Q3_ProdOps_Plan.docx`). The file name is `SPRINT-<PI.Sprint>.md`. The formats `PI = YYYY.Quarter` and `Sprint = PI.SprintNumber` match `docs/01-business/planning-roadmap-template.xlsx`.

There are **9 sprints** covering the **16 EIS (PaaS) applications** in the [PO] table "eVyoog EIS - Roadmap Initiatives". [CG] and [WB] contain no sprints.

To add a sprint, copy [`_template.md`](_template.md).
