# Source documents

These are the original planning documents behind the roadmap, sprint and application pages in [`../roadmap/`](../roadmap/). They are stored here unchanged so every reference can be traced back to its source.

| Code | File | What it contains |
|------|------|------------------|
| **[PO]** | [`2026Q3_ProdOps_Plan.docx`](2026Q3_ProdOps_Plan.docx) | The product-operations plan. It has the EIS vision, 16 applications and 69 capabilities, and the **only PI/sprint schedule** (72 rows: EIS, Macro Planner, Agile Planner, SW Life Cycle). It also describes the hosted SaaS products Thittam and Thiran, and names Tharav, Valam, Varthan and Yukth. |
| **[CG]** | [`eVyoog_EIS_Platform_-_ChatGPT2.docx`](eVyoog_EIS_Platform_-_ChatGPT2.docx) | The architecture conversation: the original requirement prompt, 16 applications and 50 capabilities, cross-cutting services, multi-region and multi-language design, the AI agent platform, MCP, and the engineering golden path. It contains phases only, no sprints. |
| **[WB]** | [`Full_SaaS_PaaS_Product_Architecture_Workbook.xlsx`](Full_SaaS_PaaS_Product_Architecture_Workbook.xlsx) | 18 sheets: Product Breakdown (16 applications, 69 capabilities, 114 features, 444 functions), APIs, Microservices, Data Entities, Events, User Roles, User Journeys, Roadmap phases, Architecture Layers, NFRs and Traceability. It contains no sprints. |

Sheet references use the form **[WB:\<sheet name\>]**.

**Rule:** do not edit these files. When the plan changes, add the new version beside the old one (with a date or version in the file name), then update [`../roadmap/`](../roadmap/).
