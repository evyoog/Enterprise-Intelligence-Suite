# API requirements — Product evaluation (REQ-MKT-005)

The API requirements live in [docs/06-api/api-requirements/product-evaluation.md](../../../06-api/api-requirements/product-evaluation.md): `POST /me/trials`, `POST /organization/me/trials`, `POST /me/demo-requests`, the public `GET /products/compare`, `trialDays` on the product, and the `trial` field on subscriptions and subscription events. The changes to the subscription, renewal-reminder, ticket and provisioning endpoints are listed there and in [subscription-lifecycle](../subscription-lifecycle/api-requirements.md).
