# Acceptance criteria — Organizations directory

| ID | Criterion |
|---|---|
| AC-1 | The list shows organizations and individuals together; there is no Individuals or Pending provisioning tab. |
| AC-2 | Each filter narrows the list; Clear filters restores it. |
| AC-3 | Each row shows profile completion and what is missing; the summary counts match the list. |
| AC-4 | Opening an organization shows the eight tabs, and Structure shows its org chart read-only. |
| AC-5 | Opening an individual shows its five tabs. |
| AC-6 | A user without `MANAGE_REGISTRATIONS` gets 403. |
| AC-7 | Completion is 100 for a fully filled organization and 0 for an empty one; the missing list names the empty items. |
