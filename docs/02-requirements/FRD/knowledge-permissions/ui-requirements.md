# UI requirements — Knowledge permissions

No screen of its own. The permissions appear on the existing Roles & permissions screens ([admin-roles-permissions.md](../../../05-ui/screen-requirements/admin-roles-permissions.md)) with the labels "Knowledge contributor" and "Knowledge publisher" (i18n `knowledge.permissions.*`). Knowledge Management screens ([knowledge-admin-*.md](../../../05-ui/screen-requirements/)) show or hide actions by permission.
