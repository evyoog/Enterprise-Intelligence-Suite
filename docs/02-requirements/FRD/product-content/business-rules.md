# Business rules — Product content

| ID | Rule | Enforced in | Source |
|---|---|---|---|
| BR-PCON-001 | Only a platform administrator with `MANAGE_CATALOG` can create, change, publish or delete product content or ask for an upload URL. Customers and visitors can only read published content. | backend (SecurityConfig and service) | REQ-CAT-004.8 |
| BR-PCON-002 | Allowed files: image PNG, JPG, WebP up to 5 MB; datasheet and case-study PDF up to 20 MB. The extension and the declared content type must both match. SVG and GIF are refused. Limits come from `eis.product-content.*`. | backend | REQ-CAT-004.2, .5, .7 |
| BR-PCON-003 | The storage key is generated by the backend (`product-content/{applicationId}/{kind}/{uuid}.{ext}`), never from the file name. An item can only use a key under its own application's prefix. | backend | REQ-CAT-004.2 |
| BR-PCON-004 | An upload counts only after the backend checked that the object exists and that its size and type match what was declared; otherwise the object is deleted and the request is refused. | backend | REQ-CAT-004.2 |
| BR-PCON-005 | A visitor sees an item only when it is Published and its application is Active. Documentation links also need a live, Public knowledge article. | backend | REQ-CAT-004.3, .9 |
| BR-PCON-006 | No response contains a credential, a bucket secret or a permanent file URL. Image links last 1 hour, downloads 5 minutes. | backend | REQ-CAT-004.10 |
| BR-PCON-007 | A video link must be `https`. YouTube and Vimeo are recognised; every other link is shown as a link only. | backend | REQ-CAT-004.6 |
| BR-PCON-008 | Editing an item or replacing its file raises its version by one and sets "Updated on"; the replaced file is deleted. | backend | REQ-CAT-004.4 |
| BR-PCON-009 | An image needs alt text; a case study needs a customer name; every item needs a title (up to 200 characters). | backend, frontend | REQ-CAT-004.5, .7 |
| BR-PCON-010 | Deleting an item or an application deletes its files from storage. | backend | REQ-CAT-004.12 |
| BR-PCON-011 | Content changes are audited with the administrator and the item. | backend | REQ-CAT-004.13 |
| BR-PCON-012 | Without configured storage, file uploads answer 503 `STORAGE_NOT_CONFIGURED`; link items still work. | backend | REQ-CAT-004.11 |

Rules shared with the knowledge media library: [BR-MED-001](../../03-business-rules/) and BR-KMED-002 (same storage, same key principle).
