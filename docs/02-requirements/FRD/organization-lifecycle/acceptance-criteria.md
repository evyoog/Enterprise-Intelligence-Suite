# Acceptance criteria — Organization Lifecycle

| ID | Criterion | Test cases |
|---|---|---|
| AC-1 | **Given** an ACTIVE organization **When** the administrator edits its details **Then** the new details are saved, the code, seats and statuses are unchanged, blank optional fields are cleared, and an `ORGANIZATION_UPDATED` audit record exists | [TC-TEN-001](../../../../test-cases/functional/organization-lifecycle/TC-TEN-001.md) |
| AC-2 | **Given** an ACTIVE organization with active members **When** the administrator suspends it with a reason **Then** its lifecycle is SUSPENDED, every active member's login is disabled and their sessions ended, the page reports the count, and an `ORGANIZATION_SUSPENDED` audit record holds the reason | [TC-TEN-002](../../../../test-cases/functional/organization-lifecycle/TC-TEN-002.md) |
| AC-3 | **Given** a SUSPENDED or CLOSED organization **When** the administrator activates it **Then** its lifecycle is ACTIVE and every active member's login is enabled | [TC-TEN-003](../../../../test-cases/functional/organization-lifecycle/TC-TEN-003.md) |
| AC-4 | **Given** an organization **When** the administrator closes it **Then** its lifecycle is CLOSED, member logins are disabled, no row is deleted, it cannot be edited or suspended, and it can be activated again | [TC-TEN-004](../../../../test-cases/functional/organization-lifecycle/TC-TEN-004.md) |
| AC-5 | **Given** Keycloak fails to update a member's login **When** a lifecycle action runs **Then** the status change stands, the page lists that member's email with a retry hint, and repeating the action retries | [TC-TEN-005](../../../../test-cases/functional/organization-lifecycle/TC-TEN-005.md) |
| AC-6 | **Given** an administrator who is an active member of the organization **When** they suspend or close it **Then** the response is 400 and the dialog shows the message; the status is unchanged | [TC-TEN-006](../../../../test-cases/functional/organization-lifecycle/TC-TEN-006.md) |
| AC-7 | **Given** an organization whose registration is pending email verification **When** it is activated **Then** no login is enabled | [TC-TEN-007](../../../../test-cases/functional/organization-lifecycle/TC-TEN-007.md) |
| AC-8 | **Given** a SUSPENDED organization **When** a member calls an organization self-service endpoint with a still-valid token **Then** the response is 403 "Your organization's account is not currently active", and it works again after activation | [TC-TEN-008](../../../../test-cases/functional/organization-lifecycle/TC-TEN-008.md) |
| AC-9 | **Given** no token, or a token without `MANAGE_REGISTRATIONS` **When** any edit or lifecycle endpoint is called **Then** the response is 401 or 403; an unknown organization returns 404 and an invalid edit 400 | [TC-TEN-009](../../../../test-cases/functional/organization-lifecycle/TC-TEN-009.md) |
| AC-10 | **Given** the Organizations tab **When** it is shown **Then** the new text exists in `en.json` and `es.json`, the controls are keyboard operable with accessible names, and a jest-axe check reports no violations | [TC-TEN-010](../../../../test-cases/functional/organization-lifecycle/TC-TEN-010.md) |
