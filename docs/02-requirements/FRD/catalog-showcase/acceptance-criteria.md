# Acceptance criteria — Catalog Showcase

| ID | Criterion | Test cases |
|----|-----------|------------|
| AC-1 | **Given** active, inactive and hidden platforms with active and inactive apps **When** anyone calls `GET /catalog/platforms` **Then** only active, shown platforms are listed, in display order, with counts, categories and tags from active apps only, and a hidden platform's details return 404 | [TC-CAT-011](../../../../test-cases/functional/catalog-showcase/TC-CAT-011.md) |
| AC-2 | **Given** invalid colour, status, display order, tag or URL values **When** an administrator saves a platform or app **Then** the API returns 400; valid values are stored (colour upper-case, tags de-duplicated) | [TC-CAT-012](../../../../test-cases/functional/catalog-showcase/TC-CAT-012.md) |
| AC-3 | **Given** the Product Catalog **When** it loads **Then** the summary cards, platform cards and app cards show real counts and data, the category filter and search narrow the results, and empty, loading and error states are shown | [TC-CAT-013](../../../../test-cases/functional/catalog-showcase/TC-CAT-013.md) |
| AC-4 | **Given** a visible platform **When** a visitor opens its details **Then** the overview, applications, features and product information are shown | [TC-CAT-014](../../../../test-cases/functional/catalog-showcase/TC-CAT-014.md) |
| AC-5 | **Given** the platform form **When** an administrator types a name, picks a preset colour and turns off "show in catalog" **Then** the live preview updates and the saved payload carries the showcase settings; invalid input shows errors only after the first submit | [TC-CAT-015](../../../../test-cases/functional/catalog-showcase/TC-CAT-015.md) |
| AC-6 | **Given** the app form **When** an administrator fills it **Then** it shows the sections Basic, Appearance, Launch & availability, Integration, Product relationships, Features, Pricing and Resources, keeps every existing field and rule (SSO hint text, "Price shown only if no pricing tiers are added", retired stays retired), and saves feature tags, links and the colour choice | [TC-CAT-016](../../../../test-cases/functional/catalog-showcase/TC-CAT-016.md) |
| AC-7 | **Given** All Apps **When** an administrator filters by status, platform or search, switches view, or deletes an app **Then** the table/cards narrow accordingly and delete asks for confirmation first | [TC-CAT-017](../../../../test-cases/functional/catalog-showcase/TC-CAT-017.md) |
| AC-8 | **Given** any redesigned screen **When** it is checked with axe **Then** there are no violations, and the colour utilities keep text at 4.5:1 | [TC-CAT-018](../../../../test-cases/functional/catalog-showcase/TC-CAT-018.md) |
| AC-9 | .11 | **Given** the catalog **When** it loads **Then** the banner and the category tiles with counts are shown; choosing a tile narrows the list to that category and choosing All clears it. | [TC-CAT-052](../../../../test-cases/functional/catalog-showcase/TC-CAT-052.md), [TC-CAT-055](../../../../test-cases/functional/catalog-showcase/TC-CAT-055.md) |
| AC-10 | .12 | **Given** products with platforms, plans and feature tags **When** a user ticks Platform, Pricing model or Feature options **Then** only matching products stay (all chosen features must match), the counts are right, Clear all resets, and Saved only appears for signed-in users. | [TC-CAT-048](../../../../test-cases/functional/catalog-showcase/TC-CAT-048.md), [TC-CAT-050](../../../../test-cases/functional/catalog-showcase/TC-CAT-050.md), [TC-CAT-054](../../../../test-cases/functional/catalog-showcase/TC-CAT-054.md) |
| AC-11 | .13 | **Given** a featured product added in the last 30 days with approved reviews **Then** its card shows Featured, New, the rating with the review count and the cheapest paid plan as the From price; a product with no reviews shows no rating and one with no paid plan shows Free. | [TC-CAT-049](../../../../test-cases/functional/catalog-showcase/TC-CAT-049.md), [TC-CAT-052](../../../../test-cases/functional/catalog-showcase/TC-CAT-052.md) |
| AC-12 | .14 | **Given** the catalog **When** the user sorts by Newest, Rating, Price or Name and switches to List view **Then** the order follows the rule, the view is remembered and the count text matches. | [TC-CAT-051](../../../../test-cases/functional/catalog-showcase/TC-CAT-051.md), [TC-CAT-056](../../../../test-cases/functional/catalog-showcase/TC-CAT-056.md) |
| AC-13 | .13 | **Given** the product list API **Then** each product carries when it was added, and `GET /products/ratings` returns the average (one decimal) and count of APPROVED reviews per product, leaving out products with none; it is public. | [TC-MKT-034](../../../../test-cases/functional/wishlist/TC-MKT-034.md), [TC-MKT-035](../../../../test-cases/functional/wishlist/TC-MKT-035.md), [TC-MKT-036](../../../../test-cases/functional/wishlist/TC-MKT-036.md) |
| AC-14 | .11 to .14, accessibility | **Given** the catalog, the cards, tiles and filter panel **Then** they pass the axe test, filters are keyboard operable, the heart announces whether the product is saved, and the layout works from phone width. | [TC-CAT-052](../../../../test-cases/functional/catalog-showcase/TC-CAT-052.md), [TC-CAT-053](../../../../test-cases/functional/catalog-showcase/TC-CAT-053.md), [TC-CAT-054](../../../../test-cases/functional/catalog-showcase/TC-CAT-054.md), [TC-CAT-058](../../../../test-cases/functional/catalog-showcase/TC-CAT-058.md) |
| AC-15 | .15 | **Given** the app form **When** an administrator uploads an app icon and a banner image **Then** each shows its own preview, both are saved with the app (`imageUrl` and `bannerImageUrl`), the banner can be removed (cleared on save), and an upload error is shown. | [TC-CAT-059](../../../../test-cases/functional/catalog-showcase/TC-CAT-059.md), [TC-CAT-060](../../../../test-cases/functional/catalog-showcase/TC-CAT-060.md), [TC-CAT-061](../../../../test-cases/functional/catalog-showcase/TC-CAT-061.md) |
| AC-16 | .13, .15 | **Given** an app with a banner image and an icon **Then** its card shows the banner image in the banner area with the icon on it; without them the tint and the initials; the form preview is the same card with nothing clickable. **Given** a wide screen **Then** the cards are narrow and as many as fit are shown on a row (four at 1440 px). | [TC-CAT-062](../../../../test-cases/functional/catalog-showcase/TC-CAT-062.md) |
| AC-17 | .16 | **Given** the catalog **when** a customer ticks Compare on up to 4 cards **then** a tray lists them with Compare now (needs 2) and Clear, and a fifth card cannot be ticked | [TC-MKT-067](../../../../test-cases/functional/product-evaluation/TC-MKT-067.md) |
| AC-18 | .17 | **Given** the app form **when** an administrator enters Free trial (days) from 1 to 90, or leaves it empty, **then** `trialDays` is saved (null when empty); other values are refused | [TC-MKT-049](../../../../test-cases/functional/product-evaluation/TC-MKT-049.md) |
