# API requirements — Tax Rules and Calculation (module `billing`)

Requirement: [REQ-BIL-002](../../02-requirements/FRD/tax-rules/requirement.md). Standard REST verbs ([C14](../../01-business/roadmap/open-decisions.md#c14)); the OpenAPI contract is generated by springdoc into `../openapi/` once built.

## Admin endpoints (`MANAGE_BILLING`)
| Method | Path | Purpose |
|---|---|---|
| GET | `/admin/billing/tax-rules` | List tax rules (`region`, `status`, `page`) |
| POST | `/admin/billing/tax-rules` | Create: body `regionId`, `taxName`, `rate`, `method` (`ADMIN_RATE` \| `TAX_SERVICE`), `effectiveFrom` |
| PUT | `/admin/billing/tax-rules/{id}` | Update the same fields |
| POST | `/admin/billing/tax-rules/{id}/enable` | Enable |
| POST | `/admin/billing/tax-rules/{id}/disable` | Disable |
| POST | `/admin/billing/tax-rules/preview` | Preview: body `amount`, `regionId` → response `taxName`, `rate`, `taxAmount`, `total`, `methodUsed` |

## Errors
Same shape as [billing-payments.md](billing-payments.md):

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Rate outside 0–100, more than 2 decimals, missing region/tax name/method |
| 403 | — | Caller lacks `MANAGE_BILLING` |
| 404 | `NOT_FOUND` | Tax rule does not exist |
| 409 | `INVALID_STATE` | A second enabled rule for the same region and effective-from date (BR-2) |
