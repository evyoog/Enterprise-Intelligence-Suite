# API requirements — Entitlements (module `registration`)

Requirement: [REQ-SUB-002](../../02-requirements/FRD/entitlements/requirement.md). Standard REST verbs ([C14](../../01-business/roadmap/open-decisions.md#c14)); the OpenAPI contract is generated by springdoc into `../openapi/` once built.

## Customer-facing endpoints
| Method | Path | Purpose |
|---|---|---|
| GET | `/me/entitlements` | The signed-in customer's own entitlements, derived from their ACTIVE subscriptions |
| GET | `/organization/me/entitlements` | The caller's organization's entitlements, per existing organization permissions |

## Admin endpoint (platform admin — permission: Open question 2)
| Method | Path | Purpose |
|---|---|---|
| GET | `/admin/customers/{id}/entitlements` | Read-only lookup of a customer's entitlements, for support |

## Internal endpoint (hosted products — to confirm with hosted product teams, Open question 1)
| Method | Path | Authentication | Purpose |
|---|---|---|
| POST | `/internal/entitlements/check` | `X-Internal-Sso-Secret` header (same convention as `InternalSsoController`), no user token | Request: `{"customerId" or "organizationId", "productId", "featureKey"?}`. Response: `{"allowed", "plan", "includedFeatures", "usageLimit"}` |

## Errors
| Status | Code | When |
|---|---|---|
| 403 | — | Internal check: missing or wrong `X-Internal-Sso-Secret`; admin endpoint: caller lacks the required permission |
| 404 | `NOT_FOUND` | Customer-facing endpoints: not the caller's own record or organization |
