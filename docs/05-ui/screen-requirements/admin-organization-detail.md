# Screen: Organization detail (`/admin/organizations/organization/:id`, `/admin/organizations/individual/:id`)

**Requirement:** [REQ-TEN-007](../../02-requirements/FRD/organization-directory/requirement.md)

- **Header:** name, code, status and lifecycle chips, profile completion, back link, actions (organization: Edit, Suspend/Activate, Close, Seats).
- **Organization tabs:** Overview (company, address, tax, billing address, administrator, region, parent, seats, dates, profile completion with missing items), Structure (read-only org chart with details and history), Members, Subscriptions, Billing, Support, Security (MFA policy, seat overage, sign-in linked), Activity (audit entries).
- **Individual tabs:** Profile (with completion), Subscriptions, Billing, Support, Activity.
